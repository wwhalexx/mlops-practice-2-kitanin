Практическая работа №2

ОС: macOS  
Python: 3.12.15  
Poetry: 2.5.1

В первой части работы было создано виртуальное окружение через venv. В проект были установлены библиотеки requests, pandas и matplotlib. После запуска программа успешно получила данные о температуре и сохранила их в файл temperature_24h.csv.

После этого зависимости были сохранены в requirements.txt с помощью команды:

```bash
python -m pip freeze > requirements.txt
```

Затем виртуальное окружение было удалено и создано заново. Все зависимости удалось восстановить из requirements.txt, после чего программа снова успешно запустилась.

Основные зависимости проекта:

- requests — используется для получения данных через HTTP;
- pandas — используется для работы с данными и DataFrame;
- matplotlib — используется для построения графика.

Также были обнаружены транзитивные зависимости:

- requests → urllib3;
- pandas → numpy;
- matplotlib → pillow.

Эти библиотеки напрямую в коде не добавлялись, но устанавливаются автоматически вместе с основными зависимостями.

Во второй части был создан отдельный проект с Poetry. Для проекта использовался Python версии 3.12.

Зависимости были разделены на группы:

- основные: requests, pandas, matplotlib;
- test: pytest;
- dev: ruff.

В plt_temp.py были внесены изменения:

- добавлен timeout для HTTP-запроса;
- добавлена проверка response.raise_for_status();
- создание DataFrame вынесено в отдельную функцию create_dataframe;
- добавлено сохранение графика в temperature_24h.png;
- основная логика программы вынесена в main().

Для функции create_dataframe был написан тест. Он проверяет названия столбцов, количество строк, сортировку по времени и соответствие температуры нужному времени.

Результат запуска теста:

```text
1 passed
```

Также была проведена проверка групп зависимостей Poetry.

При установке только основных зависимостей программа plt_temp.py работала, но pytest и ruff были недоступны.

При установке только группы test pytest работал, но ruff был недоступен, а основной скрипт не запускался из-за отсутствия requests.

При полной установке зависимостей работали и pytest, и ruff, и основной скрипт.

Для requests использовалось ограничение версии:

```text
>=2.34.2,<3.0.0
```

Команда poetry show --outdated не показала доступных обновлений. Текущая версия requests — 2.34.2, поэтому после poetry update requests версия не изменилась.

Зависимости Poetry были экспортированы в requirements.txt.

После этого виртуальное окружение Poetry было удалено. Команда:

```bash
poetry install
```

заново создала окружение и восстановила все зависимости из pyproject.toml и poetry.lock.

После восстановления тест снова прошёл успешно, а plt_temp.py запустился и создал temperature_24h.csv.

В итоге venv + pip требует вручную создавать окружение и сохранять зависимости в requirements.txt. Poetry удобнее для управления зависимостями, потому что позволяет разделять их по группам и фиксирует точные версии в poetry.lock.
